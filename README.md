# n8n Financial Lead Automation

An automated lead management workflow built with n8n for a financial advisory company.

## Overview

This workflow automates the client inquiry and notification process. When a potential client submits a service request form, the system automatically:

- Sends a thank-you email to the client
- Sends instant lead notifications to the company via:
  - Email
  - Telegram
  - WhatsApp

The workflow helps reduce manual work and ensures faster lead response time.

---

## Features

- Automated form submission handling
- Instant client confirmation email
- Real-time lead alerts
- Multi-channel notification system
- Low-code automation using n8n
